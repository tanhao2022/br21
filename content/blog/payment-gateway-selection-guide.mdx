# 支付，是盘总最容易忽视的命门

盘总，你可能在广告投放上花了大量精力——素材怎么过审、CPA怎么压低、ROI怎么优化。但有一个环节，可能正在悄悄吃掉你 **15-25%** 的利润，你却浑然不知。

这个环节就是：**支付**。

用户辛辛苦苦被你的广告吸引过来，注册了账号，决定充值——然后支付失败了。用户等了10秒，没反应，关掉页面，走了。永远不会回来。

又或者，你的支付服务商结算慢、费率高、甚至某天突然"维护"了，资金卡在里面。

这些场景每天都在发生。但太多盘总只关注"流量端"，不关注"支付端"。

## 选支付服务商，看这四个核心指标

### 指标一：交易成功率

这是最重要的指标，没有之一。

| 成功率 | 评级 | 影响 |
|--------|------|------|
| 90%+ | 优秀 | 几乎无损耗 |
| 85-90% | 良好 | 可接受 |
| 75-85% | 一般 | 每天损失15-25%流水 |
| <75% | 差 | 立即更换 |

**一个真实案例**：我们有个巴西客户，月流水$200万。原来用的支付通道成功率只有78%。换了一家成功率88%的服务商后，月流水直接涨到了$225万——多出来的$25万，全是因为之前被支付失败"漏掉"的。

成功率每提升1%，你的收入就多1%。而且这1%是 **纯利润**——不需要多花一分钱广告费。

### 指标二：费率结构

iGaming支付的费率通常比普通电商高2-3倍，因为行业风险等级高。但不同服务商的差异也很大。

**各市场费率参考：**

| 市场 | 入金费率范围 | 出金费率范围 | 行业均值（入金） |
|------|------------|------------|----------------|
| 巴西（PIX） | 1.5-3.5% | 0.5-1.5% | 2.5% |
| 菲律宾（GCash） | 2.0-4.0% | 1.0-2.0% | 3.0% |
| 越南（银行转账） | 1.0-2.5% | 0.5-1.0% | 1.8% |
| 印度（UPI） | 1.5-3.0% | 0.8-1.5% | 2.2% |
| 印尼（VA/QRIS） | 2.0-3.5% | 1.0-2.0% | 2.8% |

**注意隐性成本**：
- 有些服务商的报价不含税，实际结算时会加上5-10%的税费
- 跨境结算的换汇汇率，有些服务商会在中间价基础上加1-2%的溢价
- Chargeback（拒付）手续费，每笔$15-25

**建议**：谈费率时，要求服务商给一个 **"全包价"**（all-in rate），包含所有隐性成本。

### 指标三：结算周期与Hold比例

| 结算方式 | 说明 | 现金流影响 |
|---------|------|----------|
| T+0 | 当天结算 | 最佳，但极少有服务商提供 |
| T+1 | 次日结算 | 优秀，推荐 |
| T+3 | 3个工作日后结算 | 可接受 |
| T+7 | 一周后结算 | 勉强接受 |
| T+15 | 半个月后结算 | 不推荐，严重占用现金流 |

**Hold比例**是另一个关键条款。很多服务商会扣留每笔交易的5-20%作为"风险保证金"，在3-6个月后才释放。

举个例子：如果你月流水$100万，hold比例15%，结算周期T+7——意味着你随时有 **$15万+** 的资金被压在服务商那里。如果服务商跑路，这笔钱就没了。

**谈判建议**：
- Hold比例争取压到5%以下
- 结算周期争取T+1或T+3
- 合同中必须写明hold释放的具体条件和时间

### 指标四：合规资质

| 资质 | 重要性 | 说明 |
|------|--------|------|
| 当地支付牌照 | 必须 | 无牌照的服务商随时可能被监管叫停 |
| iGaming行业经验 | 必须 | 有针对博彩行业的风控模型 |
| PCI DSS认证 | 推荐 | 数据安全标准，保护用户卡信息 |
| 反洗钱（AML）体系 | 必须 | 没有AML体系的服务商，你也会被牵连 |

越南的支付环境相对成熟，银行转账的成功率很高。费率也是几个市场中最低的。

## 冗余策略：不要把所有鸡蛋放在一个篮子里

这不是建议，是 **铁律**。

我们见过太多盘总只接一家支付服务商，结果：
- 服务商被银行切断通道 → 全盘停摆3天
- 服务商风控升级 → 成功率从85%暴跌到50%
- 服务商跑路 → 几十万美金压款打水漂

**最佳冗余架构：**

```
动态路由系统（核心）
    ├── 主通道A（承载50%流量）
    ├── 备用通道B（承载30%流量）
    ├── 备用通道C（承载20%流量）
    └── 紧急通道D（日常不走量，仅在ABC全挂时启用）
```

**路由切换逻辑：**

| 触发条件 | 动作 | 切换时间 |
|---------|------|---------|
| 通道成功率降至80%以下 | 自动将流量切至备用通道 | <1秒 |
| 通道完全不可用 | 自动切至下一优先级通道 | <0.5秒 |
| 所有主备通道异常 | 启用紧急通道+报警 | <2秒 |
| 通道恢复正常 | 自动切回，逐步恢复流量 | 5分钟灰度 |

## 合同签订：5个必须确认的条款

在签合同前，确保以下5个条款白纸黑字写清楚：

1. **结算币种和汇率**：用美元结算还是当地货币？汇率按照哪个标准？中间价加多少点？
2. **Hold比例和释放条件**：扣多少比例？多长时间释放？提前终止合同时hold怎么退？
3. **成功率SLA**：是否承诺最低成功率？低于承诺值有什么补偿？
4. **退出条款**：提前终止合同的违约金是多少？资金多久内结清？
5. **数据报表**：是否提供实时交易看板？支持API拉取数据还是只有后台手动导出？

## 红旗信号：遇到这些情况立刻跑

| 红旗 | 说明 |
|------|------|
| 费率低得离谱（入金<1%） | 要么后面有隐性成本，要么准备跑路前割一波 |
| 不提供实时交易报表 | 数据不透明，可能存在暗扣 |
| Hold比例超过15% | 对你的资金安全不负责 |
| 拒绝提供公司注册信息 | 皮包公司概率极高 |
| 结算周期超过T+7 | 现金流风险过大 |
| 合同中没有退出条款 | 你被绑架了 |
| 只支持加密货币结算 | 可能涉及洗钱，合规风险极高 |
