# 盘总，你真的知道你在赚钱还是亏钱吗？

这是一个很扎心的问题。

我们接触过的盘总中，至少有一半人算不清自己的真实ROI。他们看的数据是优化师每天发来的日报：今天花了多少钱、注册了多少人、CPA是多少。

但这些数据只是冰山的一角。**真正决定你赚不赚钱的，是冰山下面那些看不见的成本。**

## 一个真实案例

我们有个客户，做巴西Slot，月消耗$60,000。优化师每天报的数据很好看：

| 优化师报的数据 | 数值 |
|---------------|------|
| 月广告消耗 | $60,000 |
| 月注册用户 | 12,000 |
| CPA | $5.00 |
| FTD（首充）率 | 15% |
| FTD人数 | 1,800 |

看起来不错对吧？CPA $5，FTD率15%，很多盘总看到这个数据就觉得"稳了"。

但当我们帮他做了完整的财务审计后，真实情况是这样的：

## 真实成本：比你以为的贵一倍

### 成本项1：广告费（显性）

这个最好算，就是Facebook扣的钱：**$60,000/月**。

### 成本项2：账户损耗（隐性）

做博彩投放，封号是家常便饭。这个客户一个月要烧掉15-20个广告账户。每个账户被封时：
- 账户余额无法退回，平均每个账户剩余$200-500
- 新账户前3天处于学习期，CPA比稳定期高50%

| 损耗项 | 计算 | 月成本 |
|--------|------|--------|
| 被封账户余额 | 18个账户 × $350均 | $6,300 |
| 学习期CPA溢价 | 18次 × 3天 × $150/天 × 50%溢价 | $4,050 |
| **账户损耗小计** | | **$10,350** |

### 成本项3：支付通道手续费（隐性）

PIX收款不是免费的。第三方支付通道的费率：

| 通道类型 | 费率 | 月交易额 | 月手续费 |
|----------|------|----------|----------|
| 持牌PSP | 3.5% | $85,000 | $2,975 |
| 灰色通道 | 6-8% | $85,000 | $5,100-6,800 |

这个客户用的是灰色通道，月手续费约**$5,500**。

### 成本项4：素材制作（隐性）

博彩素材的消耗速度极快，一个素材的有效生命周期只有3-5天。这个客户：
- 月产素材：120-150条
- 自有设计师：2人，月薪$1,500/人
- 外包素材：约40条 × $30/条

| 素材成本项 | 月成本 |
|-----------|--------|
| 设计师薪资 | $3,000 |
| 外包素材 | $1,200 |
| 素材工具订阅 | $200 |
| **素材小计** | **$4,400** |

### 成本项5：人力和运营（隐性）

| 人力成本项 | 月成本 |
|-----------|--------|
| 投手薪资（2人） | $4,000 |
| 客服（处理充提问题） | $1,500 |
| 技术维护 | $2,000 |
| **人力小计** | **$7,500** |

### 真实总成本

| 成本类型 | 月金额 | 占比 |
|----------|--------|------|
| 广告费 | $60,000 | 68% |
| 账户损耗 | $10,350 | 12% |
| 支付手续费 | $5,500 | 6% |
| 素材制作 | $4,400 | 5% |
| 人力运营 | $7,500 | 9% |
| **真实总成本** | **$87,750** | **100%** |

优化师报的成本是$60,000，真实成本是**$87,750**——多了**46%**。

对应的真实CPA：$87,750 ÷ 12,000注册 = **$7.31**（vs优化师报的$5.00）。

## 收入模型：钱到底赚了多少？

成本搞清楚了，再看收入端。

### FTD和ARPU

这个客户的1,800个FTD用户的充值数据：

| 用户分层 | 人数 | 占比 | 平均充值（7天） | 贡献收入 |
|----------|------|------|----------------|----------|
| 小R（充值<$20） | 1,080 | 60% | $12 | $12,960 |
| 中R（$20-100） | 540 | 30% | $55 | $29,700 |
| 大R（>$100） | 180 | 10% | $280 | $50,400 |
| **合计** | **1,800** | **100%** | **$51.7** | **$93,060** |

7天总收入$93,060，看起来大于总成本$87,750，利润$5,310。但等等，还有一个关键问题——

### 收入的时间分布

Slot用户的收入不是匀速产生的。我们的数据显示：

| 时间段 | 收入占比 | 累计收入 |
|--------|----------|----------|
| 第1天 | 35% | $32,571 |
| 第2-3天 | 25% | $55,836 |
| 第4-7天 | 20% | $74,448 |
| 第8-14天 | 12% | $85,615 |
| 第15-30天 | 8% | $93,060 |
| 第31-90天 | 追加5-8% | ~$97,700 |

**70%的收入集中在前7天。** 这意味着，如果你的7天ROAS低于1.5x，基本上不可能靠后续收入翻盘。

### 平台抽水（GGR分成）

别忘了，上面的收入是用户充值总额，不是你的净收入。还要扣掉：
- 用户提现（平均提现率30-40%）
- 平台运营成本（游戏供应商分成等）

实际可回收收入约为充值总额的**55-65%**。

| 项目 | 金额 |
|------|------|
| 用户30天总充值 | $93,060 |
| 减：用户提现（35%） | -$32,571 |
| 减：游戏供应商分成（10%） | -$9,306 |
| **净收入（GGR）** | **$51,183** |

## 盈亏平衡分析

把真实成本和净收入放在一起：

| 项目 | 金额 |
|------|------|
| 净收入（GGR） | $51,183 |
| 真实总成本 | $87,750 |
| **月净利润** | **-$36,567** |

**这个客户以为自己在赚钱，实际上每月亏损$36,567。**

怎么才能扭亏？倒推盈亏平衡点：

要让净利润>=0，需要：净收入 >= 真实成本

| 方案 | 需要达到的指标 | 当前指标 | 差距 |
|------|--------------|----------|------|
| 方案A：降成本 | 总成本降到$51,183 | $87,750 | 需降42% |
| 方案B：提收入 | GGR提到$87,750 | $51,183 | 需提71% |
| 方案C：组合优化 | 成本降20%+收入提30% | - | 可行 |

现实中，方案C是最可行的：
- **成本端**：通过BR21的合规投放降低账户损耗（省$6,000+/月）、优化支付通道降低手续费（省$2,000/月）
- **收入端**：通过[支付优化提高入金率](/zh/brazil/slot/payment/)（提升15-20%）、优化Lookalike找到更高ARPU用户（提升20-30%）

## 盘总的财务看板：每天该看什么

别再只看优化师发的日报了。以下是盘总必须自己盯的核心指标：

| 指标 | 计算方式 | 健康值 | 危险值 |
|------|----------|--------|--------|
| 真实CPA | 全部成本÷注册数 | <$7 | >$10 |
| FTD率 | 首充人数÷注册人数 | >12% | <8% |
| 7天ARPU | 7天充值÷FTD人数 | >$40 | <$25 |
| 支付成功率 | 成功充值÷发起充值 | >70% | <50% |
| 7天ROAS | 7天GGR÷真实成本 | >1.5x | <1.0x |
| 30天ROAS | 30天GGR÷真实成本 | >2.5x | <1.8x |
| 账户存活天数 | 平均每个账户使用天数 | >15天 | <7天 |

**建议每天早上花10分钟看这个看板。如果连续3天有指标进入危险区，立刻暂停投放排查原因。**

## 现金流管理：别让账面利润骗了你

即使你的ROI模型是正的，还有一个坑：**现金流时间差**。

| 事件 | 时间点 |
|------|--------|
| Facebook扣广告费 | 实时 |
| 用户注册 | 当天 |
| 用户首充 | 1-3天后 |
| 70%收入产生 | 7天内 |
| 支付通道结算到账 | T+3到T+7 |
| 汇率结算 | 按结算日汇率 |

从广告费花出去到收入回到你的账户，中间有**10-15天的时间差**。如果你的月消耗是$60,000，你至少需要准备**$30,000-45,000的现金储备**来覆盖这个时间差。

很多盘总在扩量期翻车，不是因为ROI不行，而是**现金流断了**。
